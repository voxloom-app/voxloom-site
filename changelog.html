2026-11-07 · BETA

Voxloom v0.4.0

A smarter dictionary, more speech models, and a new listening look.

What’s changed

  • Smarter dictionary: your Word dictionary now steers transcription. Terms are passed to Whisper as hints and fixed in context during cleanup (#155, #156).
  • A compact A–Z dictionary list replaces the term tiles (#165).
  • More speech models: optional Parakeet v2 and v3 (Core ML) (#160) and an English-first Whisper Large v3 Turbo (#165). Speech models are optional downloads; none are bundled.
  • An Aurora gradient in the HUD while listening and processing (#157).

Local cleanup remains optional and experimental. macOS only, no auto-update. Cleanup setup.

2026-11-04 · BETA

Voxloom v0.3.0

Dictionary spelling, simpler local cleanup setup, and dictation into Apple Messages.

This build is signed with a Developer ID and notarized by Apple.

What’s changed

  • Dictionary spellings are applied to matching words even with local cleanup off: for example, “chat gpt” becomes ChatGPT when saved that way. Matching handles case, spaces and hyphens; it does not guarantee a fix for every misheard word (#149).
  • Download the optional Qwen3 0.6B cleanup model from Settings (397 MB), with progress and Cancel, instead of needing to fetch the file by hand. Voxloom checks its size and SHA-256 before use (#152).
  • Cleanup setup now uses Download instead of manual Import. A previously imported compatible model stays installed (#154).
  • Paste dictation into Apple Messages when Clipboard fallback is enabled; Voxloom never presses Send (#148).
  • Keep the listening pill above a visible Dock (#151).

Local cleanup remains optional and experimental. macOS only, no auto-update. Cleanup setup.

2026-11-03 · BETA

Voxloom v0.2.0

This build is signed with a Developer ID and notarized by Apple.

What’s changed

  • Reduced hallucinated "Thank you" text on silence at the end of a recording: trailing silence is now trimmed before Whisper (#132)
  • Soft trail-offs at the end of a recording are cut off less often by the trailing-silence trim (#137)
  • Single-key shortcuts: you can record one key (Right ⌥, ⌃, ⌘ or ⇧, or F13–F19) as your dictation shortcut in Settings (needs Input Monitoring) (#142, #143, #144)
  • When dictation falls back to Copy in a terminal app, the message now reads “Copied. Press ⌘V to paste.” (#145)
  • Dictation can now be pasted into WezTerm, Alacritty, kitty, Ghostty and iTerm2 (with Clipboard fallback on) (#147)

Known limitations

  • macOS 13.1 (Ventura) or later only. Windows and Linux aren’t supported yet.
  • No auto-update; download new versions from the Releases page.
  • The Whisper model is not bundled; download it separately.
