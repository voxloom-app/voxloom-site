SETUP

Next steps

  1. Open the .dmg and drag Voxloom to Applications.
  2. Open Voxloom from Applications.
  3. The Whisper model is not bundled. In Settings, choose a model and download it. Downloads only happen when you start them.
  4. Grant the Microphone and Accessibility permissions.
  5. Hold Control + Shift + Space (the default, changeable in Settings), speak, release.

The install guide covers checksums, each macOS permission and the optional local cleanup model.
