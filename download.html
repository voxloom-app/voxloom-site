Download & install

BETA

Work in progress

Voxloom is in beta. Expect rough edges, and check that dictation behaves as you expect before relying on it. Found a problem or have feedback? Open an issue on GitHub Issues.

REQUIREMENTS

System requirements

  • macOS only. Windows and Linux are not supported yet.
  • Universal build (Apple silicon and Intel)
  • macOS 13.1 (Ventura) or later
  • Disk space for a Whisper model: Tiny (English) ~78 MB or Base (English) ~148 MB
  • Optional: another 397 MB for the local cleanup model
  • A microphone
SETUP

Install steps

  1. Download Voxloom_0.4.0_macos_universal.dmg from the button above.
  2. Optional: check the download against SHA256SUMS by running shasum -a 256 -c SHA256SUMS --ignore-missing in the folder that holds both files.
  3. Open the .dmg and drag Voxloom to Applications.
  4. Open Voxloom from Applications.
  5. The Whisper model is not bundled. In Settings, choose a model and download it. Downloads only happen when you start them.
  6. Grant the permissions below.
  7. Hold Control + Shift + Space (the default, changeable in Settings), speak, release.

There is no auto-update. Download new versions from Releases.

PERMISSIONS

macOS permissions

  • Microphone: to record while you hold the shortcut. macOS asks the first time you dictate. Voxloom should then appear by name under System Settings → Privacy & Security → Microphone.
  • Accessibility: to insert text into the focused field. Enable Voxloom under System Settings → Privacy & Security → Accessibility. Without it, Voxloom can copy the text to your clipboard instead, if clipboard fallback is enabled.
  • Input Monitoring: only needed if you use a single key as your shortcut. macOS asks when you save one in Settings. Allow Voxloom under System Settings → Privacy & Security → Input Monitoring, then record the key again; relaunch Voxloom if that doesn’t help. Until then Voxloom keeps your previous shortcut. The default Control + Shift + Space shortcut does not need it.
OPTIONAL · EXPERIMENTAL

Set up local cleanup

Local cleanup uses a separate on-device model to fix punctuation and drop filler words. It is not required for dictation: Whisper works without it. Cleanup is experimental; check the result before using it.

  1. In Settings, find Cleanup model and choose Download (397 MB). Voxloom downloads the pinned Qwen3 0.6B Q4_K_M model and verifies its size and SHA-256 before use.
  2. Wait for the download to finish. Progress is shown while it runs; choose Cancel to stop it.
  3. When the model is installed, enable Clean up transcripts locally.

Models download from Hugging Face only when you start them. Transcription and cleanup run on your Mac; your dictation is not sent to the model host. If cleanup fails its checks, Voxloom uses the uncleaned transcript.
